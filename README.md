# LumincoinFinance

## Описание
Этот проект представляет собой клиентскую часть приложения, разработанную с использованием  **JavaScript** в ветке "master", **TypeScript** в ветке "ts".

переключение на ветку ts 
```
git checkout ts

```
## Функционал
 ```
  1.Авторизация / регистрация. 
  2.Интерактивные графики 
  3.Добавление, удаление категорий расходов/доходов. 
  4.Добавление, удаление, изменение, расходов/доходов. 
  5.Фильтрация расходов/доходов по временным меткам. 
 ```
  
## Установка и запуск

1. Установите зависимости:

    ```bash
    npm install
    ```

2. Запустите клиентскую часть приложения:

    ```bash
    npm dev
    ```
